🤖 Smart AI Study Assistant

📌 Introduction

Smart AI Study Assistant is a Python-based application developed using Streamlit. It helps students organize their learning activities and improve their study habits.

🎯 Problem Statement

Students often face difficulties managing their study activities, tracking quiz performance, and identifying topics that need improvement.

✨ Features

- Interactive study assistant interface
- Study tips and learning support
- Quiz score tracking
- Weak topic tracking
- Daily study progress tracking
- User-friendly interface

🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- JSON

⚙️ Installation and Setup

1. Clone the repository

git clone https://github.com/kapseshreya/Smart-AI-Study-Assistant.git

2. Open the project folder

cd Smart-AI-Study-Assistant

3. Install dependencies

pip install -r requirements.txt

4. Run the application

streamlit run ai_study_assistant.py
